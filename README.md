# AI Safety at NeurIPS

An unofficial, community guide to AI safety events at NeurIPS 2026 across all three sites: **Sydney** (main, Dec 6–12), **Atlanta** and **Paris** (satellites, Dec 9–13).

**Live site:** https://varchanaiyer.github.io/neurips-2026-safety-week/

It lists official safety workshops, tutorials, keynotes and socials alongside unofficial side events, all in local time, plus the organizations present in each city and getting-around notes.

## Submit an event

Use the **Submit an event** button on the site. It opens a prefilled issue here labeled `event-submission`. You can also [open an issue directly](../../issues/new?labels=event-submission).

The site is a single static `index.html`. Event data lives in the `EVENTS` array inside it.
